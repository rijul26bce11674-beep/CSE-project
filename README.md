# Library Management System

## Project Description

The **Library Management System** is a simple Python-based project designed to manage basic library operations. It allows users to add books, display available books, issue books, and return books.

This project demonstrates basic Python programming concepts such as variables, lists, functions, conditional statements, loops, and user input.

## Objectives

* To create a simple system for managing library books.
* To add and display books in the library.
* To issue books to users.
* To return issued books.
* To understand the practical use of Python programming.

## Features

* Add new books
* Display all books
* Search for books
* Issue a book
* Return a book
* Simple menu-driven interface

## Technologies Used

* **Programming Language:** Python
* **IDE:** Visual Studio Code
* **Version Control:** Git and GitHub

## How to Run the Project

### Step 1: Install Python

Download and install Python from the official Python website.

### Step 2: Download or Clone the Project

Download the project files or clone the repository using Git.

### Step 3: Open the Project

Open the project folder in Visual Studio Code.

### Step 4: Run the Program

Open the terminal in VS Code and run:

```bash
python library.py
```

## How the System Works

When the program starts, it displays a menu with different options:

1. Add Book
2. Display Books
3. Search Book
4. Issue Book
5. Return Book
6. Exit

The user selects an option by entering the corresponding number. The program then performs the selected operation.
